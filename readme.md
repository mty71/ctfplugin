# 聖地占領戦 (CtfPlugin) 取扱説明書

4チームによる拠点を結んだ中央「聖地」の奪い合い、特殊なダウン＆救助メカニクス、インベントリ強奪システムを実装したマインクラフトオリジナル PvP プラグインです。

---

## 📅 開催スケジュール・フェーズ進行

管理者コマンド `/admin start` を実行した時点を起点とし、イベントの経過日数が自動カウントされます。

* **Day 1 〜 Day 2**
    * `18:00 - 23:00` : **通常PvPフェーズ** (`GAME_RUNNING`)
    * `23:00 - 24:00` : **占領戦フェーズ** (`OCCUPATION_TIME`) - 聖地占領でスコア加算＆キルで1pt強奪
* **Day 3（最終日）**
    * `17:00 - 22:00` : **通常PvPフェーズ** (`GAME_RUNNING`)
    * `22:00 - 終了` : **聖地決戦フェーズ** (`FINAL_DECISION`) - TOPチームの死守時間減算バトル

---

## 🚩 聖地占領ルール

1. **初期状態（白旗）**
    * 聖地中央には「白旗 (`WHITE_BANNER`)」が設置されています。
2. **占領方法**
    * 白旗を**右クリック**すると自チーム色の旗に変化し、占領状態になります。
3. **占領解除（中立化）**
    * 他チームが占領中の旗を**左クリック（破壊）**すると白旗に戻り、占領状態が解除されます（※自チームの旗は壊せません）。
4. **最終日（聖地決戦）の勝利条件**
    * ポイントTOPのチームが聖地を占領している間、チームの持ち時間がカウントダウンされます。
    * 持ち時間を `0秒` にしきったチームが完全勝利となります。
    * 他チームも占領やPvPでTOPポイントに並べば、聖地占領時に持ち時間を減算する権利を得ます。

---

## 🩸 特殊ダウン＆レスポーンシステム

プレイヤーの HP が 0 になった際、即座に死亡せず**ダウン状態**へ移行します。

* **ダウン中の状態**: 移動不可（鈍足）および視界制限（盲目）。画面下のメッセージバーにカウントダウン（30秒）が表示されます。
* **救助（味方）**: ダウン中の味方を**右クリック**で救助（HPハート3個で復帰）。
* **インベントリ奪取（敵）**: ダウン中の敵を**右クリック**すると専用インベントリが開き、相手の所持アイテムを強奪可能。
* **即時リスポーン（スニーク）**: ダウン中に**スニーク（Shift）**で拠点へ即復帰（**ランダムで5個**アイテムドロップ）。
* **時間切れリスポーン**: 30秒経過で自動復帰（**ランダムで3個**アイテムドロップ）。

## 🛠️ コマンド一覧

### 👤 一般プレイヤー用

| コマンド | 説明 |
| :--- | :--- |
| `/team` | チームヘルプを表示します。 |
| `/team join <RED\|BLUE\|GREEN\|YELLOW>` | 指定したチームに参加します。 |

### 👑 運営・管理者用 (`ctf.admin` 権限)

| コマンド | 説明 |
| :--- | :--- |
| `/admin` | 管理者コマンドのヘルプを表示します。 |
| `/admin start` | **イベントを開始します（実行時を Day 1 としてカウント開始）。** |
| `/admin setspawn <チーム名>` | 実行者の現在地を対象チームの拠点スポーン位置に設定します。 |
| `/admin setholyground` | 実行者の現在地を聖地の「旗設置場所」に設定し、白旗を設置します。 |
| `/admin setphase <フェーズ名>` | ゲームフェーズを手動変更します。 (`IDLE`, `GAME_RUNNING`, `OCCUPATION_TIME`, `FINAL_DECISION`) |
| `/admin setpoint <チーム名> <数値>` | 指定チームの所持ポイントを手動調整します。 |
